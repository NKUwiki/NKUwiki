本篇介绍**参与渠道**：从「只想提个建议」到「完整参与共建」，按投入程度从低到高有四种方式，任选适合你的即可。写作规范（文件放哪、Frontmatter 怎么写）见[贡献指南](/pages/Contributing/)。

## 四种方式一览

| 方式 | 适合谁 | 需要会什么 |
| --- | --- | --- |
| 联系项目组 | 发现错误、想提建议 | 会聊天就行 |
| 直接投稿 | 已经写好或想写一整篇文章 | 会用 Word 或 Markdown |
| 飞书协作 | 想在线快捷编辑现有内容 | 有飞书账号 |
| GitHub 协作 | 想长期参与、自己提交修改 | 会用 Git（或愿意学） |

## 联系项目组

发现问题或想提建议，不需要写文章也可以反馈：

- 加入交流 QQ 群 **1108024910**
- 发邮件至 **1352862815@qq.com**（联系 `Cure`）
- 在 GitHub 提交 [Issue](https://github.com/NKUwiki/NKUwiki/issues)

反馈时请说清楚三件事，方便我们快速定位：**哪个页面**（标题或链接）、**什么问题**（错误信息/过时内容/缺失主题）、**你的建议**（如有）。如果是事实性修正，最好附上依据（官网通知、截图等）。

## 直接投稿

已经写好或想写一整篇文章，可以直接发给我们代为上传：

1. 文章用 Markdown 或 Word 皆可；按[贡献指南](/pages/Contributing/)写好 Frontmatter 与结构最佳，不会写也可以只交正文，由我们代为整理。
2. 图片单独打包发送，并**标明每张图片插入的位置**（如「第 3 节第一段后面」）。
3. 发送到上述邮箱或 QQ 群，管理员审核后会替你上传并署名。

## 飞书协作

我们维护了[飞书文档](https://nankai.feishu.cn/wiki/WvfswczB4iE2gxkKVFGcfqvPn7b?from=from_copylink)，适合在线快捷编辑：

- 左侧分栏有**新生入学、浅谈学习、群汇总、校园生活**等分区，可以直接修订现有篇目或新增内容。
- 飞书里的修改不会自动同步到站点，管理员会定期搬运；**改动后请到 QQ 群说一声**，并说明修改时间、修改人与修改内容，避免遗漏。

## 通过 GitHub 协作

适合长期参与、希望自己的修改直接上站的贡献者。第一次贡献请先 **Fork** 本仓库到个人账号：

![找到 fork](/img/10/02/找到fork.png)

### 01. 同步最新代码

Wiki 更新较频繁，动手前先在个人仓库点 `Sync fork` 同步他人的修改：

![sync fork](/img/10/02/sync_fork.png)

### 02. 编辑内容

两种方式任选：

- **网页端**：在 GitHub 上直接编辑文件、新建文章，适合小改动或上传已写好的文章；
- **本地**：用 Git 把仓库 clone 到本地，按[贡献指南](/pages/Contributing/)新建文章与图片，本地 `pnpm dev` 预览确认后 push 回**个人仓库**。Git 的使用可以参考[这份 Git 教程](https://wiki.ncepuinfo.cc/pages/GitStudy/)。

![编辑内容](/img/10/02/edit_contents01.png)

### 03. 提交 Pull Request

个人仓库更新后，点击 `Contribute → Open pull request` 把修改提交到主仓库：

![PR](/img/10/02/PR.png)

CI 会自动运行格式检查与构建，管理员审核通过后即自动发布上线；如有问题会在 PR 里评论，请留意修改。

### 提交 PR 前的检查

- 新文章放在正确的编号目录、Frontmatter 完整（见[贡献指南](/pages/Contributing/)）
- 图片放入 `docs/public/img/目录编号/文章编号/`，正文引用路径正确
- 本地 `pnpm check` 与 `pnpm build` 均通过（网页端编辑可跳过，CI 会代跑）
- 涉及站点配置、主题或构建脚本的改动，请在 PR 描述里说明动机与影响范围

## 行为准则与许可

参与本项目即视为同意遵守[社区行为准则](https://github.com/NKUwiki/NKUwiki/blob/main/CODE_OF_CONDUCT.md)。提交的文章与素材按项目双协议（代码 MIT、内容 CC BY-NC-SA 4.0）授权发布。
