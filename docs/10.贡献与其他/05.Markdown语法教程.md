本页是投稿写作的语法速查：上半部分是通用 Markdown，下半部分是本站专属扩展。每个语法都同时给出**写法**（代码块内）与**渲染效果**。更偏实现细节的说明（参数表、接线方式）见[站点功能说明](/pages/SiteFeatures/)。

## 标题

正文从 `##` 开始用（`#` 一级标题由系统自动生成，正文不要再写）；`##` 与 `###` 会进入右侧目录。

```md
## 二级标题（进目录）

### 三级标题（进目录）
```

## 文字强调

| 语法 | 效果 | 用途 |
| ---- | ---- | ---- |
| `**加粗**` | **加粗** | 常规强调 |
| `*斜体*` | *斜体* | 书名、术语、外语词 |
| `~~删除线~~` | ~~删除线~~ | 过时信息 |
| `` `行内代码` `` | `行内代码` | 文件名、命令、按键 |
| `==马克笔==` | ==马克笔== | 最高级重点：考试重点、必背内容 |

马克笔是本站扩展，`{.配色}` 可换颜色（`info` / `note` / `tip` / `warning` / `danger` / `caution` / `important`）：

```md
==必背=={.tip} 与 ==易错点=={.warning}
```

==必背=={.tip} 与 ==易错点=={.warning}

## 行内注释与隐秘文本

- 行内注释 `{^内容}`：渲染成 `※` 小气泡，悬停/点按显示，适合名词解释（^ 后不要紧跟数字，避免误伤数学上标）：

	示例：南开大学{^简称「南开」，位于天津市}创建于 1919 年。

- 隐秘文本 `!!内容!!`：黑幕遮住、悬停显示，适合防剧透卖关子；`{.click}` 改为点击开合，`{.blur}` 改为模糊：

	示例：你知道吗， !!鲁迅!! 曾说过：" !!我没说过这句话！!! "。

## 链接与图片

```md
[站内链接](/pages/Contributing/)
[外部链接](https://example.com/)
![图片描述](/img/04/08/新开湖.png)
```

- 站内链接用文章的 `permalink`；图片放 `docs/public/img/` 对应目录，路径以 `/img/` 开头
- 图片的**描述文字会作为点击放大后的题注**，请认真填写
- 本地图片构建期自动注入宽高防止页面跳动；点击任意正文图片可全屏预览、缩放、左右切换

## 代码块

三个反引号开头，标注语言获得高亮；语言名后写 `title="文件名"` 可加标题栏（本站扩展）：

````md
```ts title="config.mts"
export default {}
```
````

```ts title="config.mts"
export default {}
```

## 提示容器

VitePress 内置容器，适合写注意事项（容器标记与内容之间要空一行）：

```md
::: tip 小技巧
这里是提示内容。
:::
```

::: tip 小技巧
这里是提示内容。
:::

`tip`（绿）/ `info`（灰）/ `note`（灰）/ `warning`（橙）/ `danger`（红）/ `caution` / `important` 均可用。

## 组件

正文中可直接使用的常用组件（参数详见[站点功能说明](/pages/SiteFeatures/)）：

| 组件 | 用途 |
| ---- | ---- |
| `<RepoCard repo="vuejs/vitepress" />` | GitHub 仓库卡片（星标、License、可见性） |
| `<Gallery>…图片…</Gallery>` | 图片画廊（等高铺满排版） |
| `<WikiSwiper>…图片…</WikiSwiper>` | 横滑轮播 |
| `<AppCards :links="[…]">` | 应用卡片网格 |
| `<DownloadPageImage />` | 页面分享长图下载按钮 |

::: warning 组件与 Markdown 混写的注意点
`<Gallery>`、`<WikiSwiper>` 等包裹型组件的标签与内部内容之间**必须留空行**，内容才会被当作 Markdown 解析；`links` 这类属性值里不会渲染 Markdown 语法。
:::

## 思维导图

用 `markmap` 语言名的代码块渲染可缩放的思维导图，块内写普通 Markdown 列表，适合章节知识结构梳理：

````md
```markmap
- 章节主题
  - 子节点一
  - 子节点二
```
````
