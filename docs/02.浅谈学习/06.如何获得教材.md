教材购买的方式大致有 3 种，各自的优缺点如下：

| 方式       | 好处                           | 缺点                                 |
| ---------- | ------------------------------ | ------------------------------------ |
| 买全套新书 | 书很全面，覆盖大一全年上课用书 | 很贵，全部原价售卖；很多书根本用不到 |
| 收二手书   | 价格低，单本大致 5~10 元       | 所有书都要自己买，稍有些麻烦         |
| 用电子书   | 成本最低                       | 部分同学可能不适应用电子书           |

## 买全套新书

学校官方会提供买大一全年教材的渠道，价格大致为 1000 元。
好处是书很全面，覆盖了大一全年上课用书。但缺点就是很贵，所有书全部是原价售卖（所以一本就三四十的样子）。并且买的书中很多根本不会用到，比如各种英语阅读，军理教材等。

## 收二手书

可以照着学校教材套餐中的书目，自己去买二手书。收购的渠道可以是从学长学姐处收（二手书交易群见**其他实用信息篇**，单本书价格大致在 5~10 元不等），也可以尝试在**闲鱼/拼多多/淘宝/孔夫子**上收。值得注意的是，思政类课程用书经常更新，购买时一定要买最新版。另外英语的教材视班型的不同（英语分为 ABC 类班），要求也有所不同，可以在第一周上课时了解清楚用书要求再购买。

## 用电子书

这应该是成本最低的一种方式，下面主要介绍可以在哪里找到电子书。

### 热心学长整理的网盘资料

[百度网盘（提取码 iNKU）](https://pan.baidu.com/s/1XEdQ580od2ExjIEDnVg0mA?pwd=iNKU)
有学长整理了工科大类的书籍电子版。

另外两份同学整理、持续更新的资料，教材只是其中一部分：

- [NKUStudy](https://nkustudy.top/)：主要提供**课件**，也有一些课程评价和经验分享，胜在比较全，网页和微信小程序都可查看。
- [NKU 计网 软件 人智大类生存手册](https://nankai.feishu.cn/wiki/O36Dw5fQVibzsnkx4ptcZreDnAf)：面向计网、软件、人智三个学院的学生，这三个学院需要学哪些课程、什么时候上，以及相关的经验、材料、课件、习题都非常详尽。

### Z-Library 等平台

- [Z-Library](http://z-lib.rest/)：全球最大的免费书籍网站
- [Library Genesis](https://libgen.gs/)：适合找英文书
- [鸠摩搜索](https://www.jiumodiary.com/)：找电子书、课程与二手书的一站式平台

### 闲鱼等电商平台收电子版

可尝试在常见电商平台搜索你需要的教材的电子版。

### 淘宝/拼多多代找书服务

如果前面那么多方法没找到你需要的电子书，那么可以尝试代找书服务，在淘宝/拼多多搜索「代找书」，然后把书的 ISBN 码发给客服，让对方帮你找电子版。
