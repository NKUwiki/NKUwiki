# 如何获得教材

::: info 此部分未完成
:::

教材购买的方式大致有3种: 

## 买全套新书

学校官方会提供买大一全年教材的渠道, 价格大致为1000. 
好处是书很全面，覆盖了大一全年上课用书。但缺点就是很贵，所有书全部是原价售卖（所以一本就三四十的样子）。并且买的书中很多根本不会用到，比如各种英语阅读，军理教材等。

## 收二手书

可以照着学校教材套餐中的书目，自己去买二手书。收购的渠道可以是从学长学姐处收（二手书交易群见**其他实用信息篇**，单本书价格大致在5-10元不等），也可以尝试在**闲鱼/淘宝/孔夫子**上收。值得注意的是，思政类课程用书经常更新，购买时一定要买最新版。另外英语的教材视班型的不同（英语分为ABC类班），要求也有所不同，可以在第一周上课时了解清楚用书要求再购买。
好处是购书价格低，缺点可能就是所有书都要自己买，稍有些麻烦。

## 用电子书

这应该是成本最低的一种方式，下面主要介绍一下可以在哪儿找电子书

### i.**热心学长提供好了**
https://pan.baidu.com/s/1XEdQ580od2ExjIEDnVg0mA?pwd=iNKU
有学长整理了工科大类的书籍电子版

### ii.**ZLibrary等平台**
zlibrary是全球最大的免费书籍网站，可以在里面搜索下载书籍
官网：https://z-library.sk/ （需要魔法）
Library Genesis(适合找英文书)：https://libgen.gs/
鸠摩(找电子书、课程，二手书一站式平台):https://www.jiumodiary.com/
### iii.**闲鱼等电商平台收电子版**
可尝试在常见电商平台搜索你需要的教材的电子版
### iiii.**淘宝/pdd代找书服务**
如果方法iii没找到你需要的电子书，可以尝试代找书服务，在淘宝/pdd搜索“代找书”，然后把书的isbn码发给客服让ta帮你找电子版
