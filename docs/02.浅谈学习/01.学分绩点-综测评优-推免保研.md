## 学分和绩点

| 名称                | 是什么                                                                                                                                              |
| ------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------- |
| 学分                | 大学里每一门课程都有一定的学分。只有课程总评成绩合格（绩点 1.0 及以上、两级制的通过为合格），才能获得相应的学分。只有学分积累到专业要求后才能毕业。 |
| 绩点                | 一种成绩的评估方式，详见下表                                                                                                                        |
| 学分绩点            | 单门课的加权成绩 = 课程绩点 × 这门课的学分                                                                                                          |
| GPA（平均学分绩点） | 平均学分绩点（GPA）= ∑ 已修课程学分绩点 ÷ ∑ 已修课程学分                                                                                            |

::: tip
实行两级制（通过 / 不通过）的课程不设置等级、绩点，不参与平均学分绩点（GPA）计算。
:::

等级、绩点与百分成绩的对应关系如下：

| 等级 | 绩点 | 百分分数段（X） | 等级 | 绩点 | 百分分数段（X） |
| ---- | ---- | --------------- | ---- | ---- | --------------- |
| A    | 4.0  | 90≤X            | C    | 2.0  | 69≤X<72         |
| A−   | 3.7  | 85≤X<90         | C−   | 1.7  | 66≤X<69         |
| B+   | 3.3  | 81≤X<85         | D+   | 1.3  | 63≤X<66         |
| B    | 3.0  | 78≤X<81         | D    | 1.0  | 60≤X<63         |
| B−   | 2.7  | 75≤X<78         | F    | 0    | X<60            |
| C+   | 2.3  | 72≤X<75         | —    | —    | —               |

更完整的说明详见[NKUStudy · 课程总评成绩和 GPA 如何计算？](https://nkustudy.top/guides/course-grade-and-gpa/)。

## 推免（保研）

::: tip
南开大学的保研率在 30% 左右。说多不多，说少不少——希望大家先规划好自己的人生再做决定，而不是盲目升学。
:::

::: timeline
- 大三下（3~6 月）
  time="大三下" type="tip"

  各校夏令营陆续开放报名，要准备材料投递，并提前联系意向导师。
- 暑假（7~8 月）
  time="暑期"

  夏令营集中举办，「优秀营员」不等于录取，要注意院校可能反悔。
- 大四上（9 月）
  time="9 月" type="warning"

  学院开展推免工作，申请推免的这段时间会很忙。
- 9 月下旬
  time="9 月底" type="tip"

  推免系统开放，填报志愿、参加复试、接受待录取。
- 10 月下旬
  time="10 月下旬" type="danger"

  推免服务系统关闭，志愿填报和待录取确认须在此前完成。
:::

::: warning
推免看**前三学年**（前六学期）的综测排名。
:::

限制条件：

| 项目 | 说明                                                                         |
| ---- | ---------------------------------------------------------------------------- |
| 挂科 | 多数学院有挂科记录就不能报名；即便允许报名，挂科也会拉低绩点，和不能报差不多 |
| 英语 | 部分学院要求四级 425 分及以上                                                |

保研经验和部分学院的推免细则，可以看这份飞书文档[NKU 计网 软件 人智大类生存手册 - 保研](https://nankai.feishu.cn/wiki/EJumwv42Fi6GMRkmTvecuhBjnde)。
