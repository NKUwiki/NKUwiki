## 课程成绩

课程总评成绩由平时、期中、期末成绩按课程大纲规定的权重加权核定，具体情况请询问任课老师。

| 记分方式                | 合格线                      |
| ----------------------- | --------------------------- |
| 等级制                  | 绩点 1.0 及以上（D 及以上） |
| 两级制（通过 / 不通过） | 通过                        |

合格才取得学分。凡考核不合格的课程，如要取得该课程学分，均应重修。

## 缓考、缓修与重修

|          | 缓考                                      | 缓修                                             | 重修                                           |
| -------- | ----------------------------------------- | ------------------------------------------------ | ---------------------------------------------- |
| 适用情形 | **考试安排冲突**（两门课同一时间考）      | **患病或突发意外**无法参加考试                   | 课程总评成绩不合格，即**挂科**                 |
| 何时申请 | 考前                                      | 考前；特殊情况最晚考后 3 天内                    | —                                              |
| 需要材料 | 《缓考申请表》                            | 证明材料 + 《缓修课程申请表》                    | —                                              |
| 结果     | 另行安排考试，一般为正常考试后下 2 个课时 | 再次修读时，需重新选课并按要求完成学习、参加考试 | 在选课的预选、正选、补退选阶段从「重修」通道选课 |

缓考是「换个时间考」，缓修是「这学期先不修这门课了」，重修是「挂了重新来」。三者都不是补考——本校没有补考制度。

## 挂科

::: warning
挂科虽可怕，但**可不要作弊**——挂了还能重修，作弊的代价远不止一门课。
:::

### 补考：本校不设

南开大学没有「补考」这一制度。总评不合格想拿学分，只有一条路：**重修**。

重修要走正常选课流程，下学期选课时记得选上。

### 学业警示

| 触发条件                                            | 说明                   |
| --------------------------------------------------- | ---------------------- |
| 同一学期内 **14 学分（含）以上**课程不合格          | 重修学分不累积统计     |
| 自入学之日起**前 2 学年**内获得学分**低于 50 学分** | 不含休学、参军入伍时间 |

学院每学期统计上一学期学分，由学生工作部门出具**学业警示通知单**，送交本人及家长，同时报教务部备案。

### 退学红线

有下列情形之一，应予退学：

- **受到学业警示后，再次达到学业警示条件**（最常见的退学原因）
- 休学、保留学籍期满，逾期 2 周不办复学，或复学审查不合格
- 确诊疾病或意外伤残，无法继续在校学习
- 未请假离校，连续 2 周不参加学校规定的教学活动
- 超过规定期限未注册且无正当事由
- 基本修业年限期满未申请延长或最长学习年限期满，且未达到结业条件

### 毕业、结业与肄业

学习年限：基本 4 年（临床医学、口腔医学 5 年）；可申请提前 1 年毕业；基本修业年限最后一学期可申请**延长**，最多 2 年（延长期按规定收取学费，纳入下一年级管理）。

| 结果 | 什么情况                                           | 证书                   |
| ---- | -------------------------------------------------- | ---------------------- |
| 毕业 | 修满培养方案全部学分 + 体测合格 + 思想品德考核合格 | 毕业证书               |
| 结业 | 未达毕业要求，但符合下方情形之一                   | 结业证书（不是毕业证） |
| 肄业 | 退学，学满 1 学年且学分 ≥ 20；不能复学             | 肄业证书               |

结业的三种情形（学分或体测至少差一项）：

| 学分                         | 体测                 |
| ---------------------------- | -------------------- |
| 修满全部应修学分             | 未达体测合格要求     |
| 已获应修总学分 90%（含）以上 | 基本达到体测合格要求 |
| 已获应修总学分 90%（含）以上 | 未达体测合格要求     |

结业不是终局：未到最长学习年限结业离校的，可在最长学习年限内回校补修课程、补测体测，满足毕业要求后**换发毕业证书**（证书日期按实际发证日填写）。但最长学习年限期满才结业的，不再换发。

::: tip 体测是独立的硬门槛
体测四年综合评定不到 50 分不能毕业，这一条和学分无关。因伤病可凭医院证明申请免测，但要走审核流程，建议尽早办理。
:::
