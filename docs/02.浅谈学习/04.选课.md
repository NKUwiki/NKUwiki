# 选课

## 一些黑话及流程介绍

A类课、B类课：全校或者全大类都必修的课，比如英语，军理，思政等

C类课：专业必修课，本专业必修的课

D类课：专业选修课，就在一堆专业课中选择一部分修读，有最低学分要求

E类课：通识选修课，就是所谓的选修课，有14学分的毕业要求。具体要求：

> 通识选修课程设置包括六个模块：公能素质和服务中国、艺术审美与文化思辨、 科学精神与健康生活、社会发展与国家治理、工程素养与未来科技、世界文明与国际 视野。学生原则上需在六个模块中至少选择四个模块修读，每模块修满不少于 2 学 分课程。其余学分可以继续修读通识选修模块课程，也可以将已获得的跨学院课程、 参加国际交流学习研究、境外课程等学分认定为通识选修课学分
>

总结一下就是六个模块至少有4个模块修的学分不少于2学分。同时可以用一些特定课程进行学分替代

### 选课流程

预选—正选—补退选（[选课通知](https://jwc.nankai.edu.cn/2025/0818/c35933a576227/page.htm)中选课手册.pdf里有详细权威的讲解，建议查看阅读）

#### 预选

预选阶段即大家有所耳闻的抢课阶段，今年非大一年级是8月24日上午11点开始。这个时候就需要“抢课”，通识必修课的预选名额是选课名额的110%。比如某高数只收150个人，则预选最多有165人能报这门课（超过165后这门课就被抢完了，报不了了）。E课预选无名额上限，比如茶道文化，虽然只收50人，但预选1000人报也没问题。

#### 正选

正选阶段，预选名额超过课程计划名额的课会随机掉人。比如某高数只招收150人，但有165人报了，就会在这165人中随机掉15人，留150人。如果你勾选了“代理补选”这个选项，系统会自动把你分配到没被报满的高数课上，如果没勾选，你高数就掉课了，只能想办法自己找没报满的高数课上。E课同样是随机掉人。比如茶道文化如果1000人报了，但只收50人，系统就会在1000人随机掉人，最后留下50人。

同时**正选阶段能退课**。比如你担心你运气不好E类课全掉了，可以一口气报5门，如果最后留下了3门，你又只是想修1门，就可以退其中2门，留下1门。**正选阶段每天下午1点会统一放出所有退课名额**。如果你有某门心仪的课没抢上，可以每天下午1点留意有没有退课名额释放。（因此还诞生了py交易，你跟某人商量好把课送给ta，你就把课退了，ta1点卡点准时抢。一般在集市上面找）

#### 补退选

第一周教学周为试听周，你如果上课感觉不太满意，可以回去把它退了，无任何影响。同时这一周你也可以留意心仪的课程有没有余课释放。同时这一周选课无任何限制，你可以报任何没有报满的专业课。

## 选课Q&A

### 1. 课需要抢吗？怎么抢？

预选即是抢课的时候。需要点进选课界面，卡点抢课。好课一般秒没。所以推荐大家把自己最想抢的课放前面。抢课顺序因人而异，有些人会先抢体育，有些会先抢高数或其他。E课因为预选无名额上限，不存在被抢完的可能，因此一般放到最后来选。

### 2. 我怎么知道学校里有哪些课程？

1. 每学期教务老师会发布选课手册（[2024秋选课手册](https://gitee.com/akanekawii/fresh-nkuer.-wiki2/raw/main/Files/2024%EF%BD%9E2025%E7%AC%AC%E4%B8%80%E5%AD%A6%E6%9C%9F%E9%80%89%E8%AF%BE%E6%89%8B%E5%86%8C.pdf)），上面罗列了所有课程及其开课单位，归属模块类型，学分等信息，可在其中查询了解

2. 可直接在选课系统里筛选课程并了解详情（选课系统开放后会更新截图及教程）

### 3. 我怎么知道哪些老师讲的好，哪些需要避雷？

1. 可以在校园集市（一个论坛，见**其他实用信息篇**）里搜索或者求助

2. 推荐关注“**枝上进化论AzureExpress**”，他们每学期都会更新课程评价，这里放一个[去年的版本](https://gitee.com/akanekawii/fresh-nkuer.-wiki2/raw/main/Files/%E9%80%89%E8%AF%BE%E6%89%8B%E5%86%8C%EF%BC%88%E6%9E%9D%E4%B8%8A%E8%BF%9B%E5%8C%96%E8%AE%BA%E5%8D%97%E5%BC%80%E9%80%89%E8%AF%BE%E6%89%8B%E5%86%8C-2023%E7%A7%8B%EF%BC%89.xlsx)，今年新生选课版本[不可错过的枝上NKU新生选课手册1.0, 我们来咯!](https://mp.weixin.qq.com/s/T6UhUcyk3htKtJQT0p2MrA)

### 4. 一学期能选多少门课？有选课学分上限吗？超过这个上限会怎样？

很多同学担心自己运气不好，E课全掉了，会多选几门E增加选上的概率，那最多能选多少门呢？学校官方给的上限是32学分（不适用于信安法等双学位的同学），但每个院的教务老师都可修改这个上限，比如人工智能学院的同学选课学分上限就是42学分，因此具体学分上限是多少建议咨询教务老师。如果选课超过这个上限，据说很容易掉课。

### 5. 学院给了推荐课表，我可以不按这个课表选课吗？

可以，但有一定风险。尤其不建议跨院/跨大类选相似的课来替代；比如你是信科大类，你选电光学院的程序设计替代计算机学院的程序设计，计算机学院可能是不认的。一般不按学院课表选是因为自己另一门想选的课程跟学院课表冲突的，就只能自己东拼西凑一下课表来保证能选上那门。无特殊情况建议按学院推荐课表选课。

### 6. 我可以选其他学院专业课吗？

可以的，但不太好抢，同时学起来可能有难度。预选阶段是不能选其他学院专业课的，正选和补退选阶段有机会，但此时其他院的同学已经在预选阶段选完他们专业课了，专业课名额可能所剩无几或者被选完了，因此很难再选上（有些课设有专门的跨院选课名额，但名额较少，也需要抢）。如果真的有某门特别想学的课，可以联系该院教务老师加课的名额；也可以尝试辅修该专业学习。
