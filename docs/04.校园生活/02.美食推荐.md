# 美食推荐

> 本页汇总校内（西南村）与校园周边商圈（八里台、津南）的美食，由访客共同评分维护。人均与推荐菜是编辑参考值，欢迎在评论区指正；想推荐新店直接在页面底部留言即可。

## 怎么用

- **看分**：卡片上的星星是大家的平均分，旁边显示评分人数。
- **打分**：点卡片下方的五角星选择分数，再点「评价」打开详情，填好昵称、邮箱后点「只提交评分」，或写几句话一并提交。
- **翻评论**：点「评价」打开详情弹窗，可以看到地点、人均、推荐菜和历史评论，每家店的评论互相独立。

## 八里台 · 西南村（校内）

西南村是校内的老牌美食聚集地，包子铺、面馆、小吃一应俱全。

## 校外商圈

八里台校区的**大悦城（南开店）**、**鲁能城**，津南校区的**吾悦广场**、**新华城市广场**、**永旺梦乐城**是同学们最常去的五个商圈，用上方的校区筛选可以快速切换。
