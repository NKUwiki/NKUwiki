# 美食推荐

> 本页汇总校内（西南村）与校园周边商圈（八里台、津南）的美食，由访客共同评分维护。人均与推荐菜是编辑参考值，欢迎在评论区指正；想推荐新店，用卡片墙上的「＋ 投稿一条」生成数据后留言即可。

## 怎么用

- **看卡片**：封面左上角是校区，名字下面是地点标签和口味标签，再下一行是简介；卡片底部只有大家的平均分和一个「评价」按钮。
- **先选校区，再看分类**：八里台和津南相距 20km，食堂名字也完全不一样，所以筛选分两层 —— 上面一行选校区（全部校区 / 八里台 / 津南），下面一行才是地点分类。选「全部校区」时列全部地点分类；选某个校区时只列这个校区有的分类（津南现在只有校外商圈）。
- **按地点筛**：分类就是地点 —— 食堂按「一食堂一楼 / 二食堂二楼 / 三食堂三楼 ……」拆开，校外分「西南村」和「校外商圈」（大悦城、鲁能城、吾悦广场、新华城市广场、永旺梦乐城都在这一个分类里，具体看卡片上的地点标签）。
- **打分**：点「评价」打开详情，在「评价」卡里点星星选分数，填好昵称、邮箱后点「只提交评分」，或直接在下面写几句话一并提交。
- **看详情**：详情左边是实拍轮播 —— 主图下方一排缩略图，点哪张跳哪张（也可以左右箭头或键盘方向键翻，点图放大看），右边是简介、详细介绍、人均与推荐菜。图片只占一屏上半截，紧跟着就是「评价」卡，平均分的星星和评论框在同一个卡片里。每家店的评论互相独立。
- **投稿**：卡片墙上方的「＋ 投稿一条」会边填边画出卡片的样子（「卡片预览 / 数据条」两个页签可切换），确认没问题再复制数据条。选了食堂楼层，校区与地点会自动跟着填好。复制后贴到页面底部留言，或者点「去 GitHub 提 issue」。详情弹窗里也有「基于这条投稿」，会把这家店现有信息整条带进表单 —— 只改人均、简介或补图时 id 保持不变，等于修订这一条；改了名称或地点才算新记录。

## 八里台 · 西南村（校内）

西南村是校内的老牌美食聚集地，包子铺、面馆、小吃一应俱全。

## 校外商圈

八里台校区的**大悦城（南开店）**、**鲁能城**，津南校区的**吾悦广场**、**新华城市广场**、**永旺梦乐城**是同学们最常去的五个商圈，用上方的校区筛选可以快速切换。
