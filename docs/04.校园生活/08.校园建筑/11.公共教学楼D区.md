D 区和 C 区是一对，课表上「C」「D」看错一个字母就要多走一段。D 区在图书馆正北偏西三百多米，周边比较空旷，以图书馆作参照最好认。

图纸收齐后一层一行，同层分段的拆成两行。收图时顺手记下这几项，单看图纸容易漏：

- 教室号段与走向，以及和 C 区号段的区别；
- 每层教室数量与大教室位置；
- 从图书馆、C 区分别怎么走过来；
- 楼梯、电梯、卫生间、饮水点位置；自习开放情况；

## 周边参照

周边一百八十米内没有其他已收录的点位，所以找楼时以图书馆为参照：从图书馆向北直走，途中会先经过 C 区一带。
