组合教学中心在校园西北角，是几栋教学空间连成的组团，不是单独一栋方盒子。第一次来最容易犯的错是进了一栋却要去另一栋的教室，所以这篇的重点是分区与连通。

## 基本信息

| 项目 | 内容                                      |
| ---- | ----------------------------------------- |
| 校区 | 八里台校区                                |
| 类型 | 公共教学组团                              |
| 位置 | 校区西北部，田家炳音乐厅以北约 50 米      |
| 地图 | [在校园地图中定位](/map?id=n_teaching_05) |

图纸收齐后一层一行，同层分段的拆成两行。收图时顺手记下这几项，单看图纸容易漏：

- 组团内各栋、各区的编号规则，以及楼栋之间的连通层；
- 每个分区对应哪些教室号段；
- 从哪个入口进最接近目标教室；
- 楼梯、电梯、卫生间在连通体中的位置；

## 周边参照

正北约 50 米是田家炳音乐厅；东南约 110 米是中心实验室，一百三十米左右是化学学院分析科学研究中心；南侧一百六十米是数学科学学院。从西区公寓方向过来最近。
