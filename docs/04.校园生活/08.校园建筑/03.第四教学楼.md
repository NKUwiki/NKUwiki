第四教学楼与第五教学楼只隔七十来米，课表上写「四教」就是这里。它在主楼西北一百多米，第一次找楼时以主楼西侧的西南联大纪念碑作参照，不容易走错。

## 基本信息

| 项目 | 内容                                      |
| ---- | ----------------------------------------- |

| 类型 | 公共教学楼                                |
| 位置 | 主楼西北，距主楼约 120 米                 |
| 地图 | [在校园地图中定位](/map?id=n_teaching_02) |

图纸收齐后一层一行，同层分段的拆成两行。收图时顺手记下这几项，单看图纸容易漏：

- 教室号段与走向：从哪个门进、号数往哪个方向递增；
- 大教室与小教室的分层分布；
- 卫生间、饮水点、教师休息室的位置；
- 晚间与周末是否开放自习；

## 周边参照

西北约 70 米是西南联大纪念碑，东南一百二十米是主楼；西南约 80 米就是第五教学楼，两栋之间穿过去比绕大路快；东北方一百五十米左右是学生活动中心。
