适用于 Linux 的 Windows 子系统（WSL）是 Windows 的一项功能，可用于在 Windows 计算机上运行 Linux 环境，而无需单独的虚拟机或双系统。

## 安装方式

- 单个命令安装

  为简单起见，通常建议使用 `wsl --install` 安装 WSL，请确保操作系统为 Windows 10 版本 2004（内部版本 19041）或更高版本，或 Windows 11。
- 手动安装
  
  如果运行的是较旧的 Windows 版本或 Windows Server Core，则可能不支持使用 `wsl --install` 安装，请参阅[手动安装步骤](https://learn.microsoft.com/zh-cn/windows/wsl/install-manual)

::: warning
如果你的 Windows 账户名包含中文（如「张三」），WSL 的安装和配置过程可能失败或报错。如果遇到此问题，建议先创建一个纯英文的 Windows 本地账户，在该账户下安装 WSL。
:::

## 单个命令安装

1. 按 `Win + X`，选择「终端（管理员）」。
2. 执行安装命令
  ``` cmd
  wsl --install
  ```
  这一条命令会自动完成以下所有工作：
   - 启用可选的 WSL 和虚拟机平台组件
   - 下载并安装最新 Linux 内核
   - 将 WSL 2 设置为默认值
   - 下载并安装 Ubuntu Linux 发行版（完成后需重启计算机）

如果遇到任何问题，请查看[排查安装问题](https://learn.microsoft.com/zh-cn/windows/wsl/troubleshooting)一文。

::: tip
如安装卡住或下载缓慢，可以尝试改为从网络直接下载：`wsl --install --web-download`。如果想安装 Ubuntu 以外的其他发行版，可用 `wsl --install -d <DistroName>` 指定发行版名称，可安装的列表可通过 `wsl --list --online` 查看。
:::

## 设置 Linux 用户名和密码

安装并重启完成后，使用“开始”菜单打开该发行版（默认情况下为 Ubuntu）。系统会依次提示你设置用户名和密码：

```text
Enter new UNIX username:
New password:
Retype new password:
```

需要注意的是：

- 用户名和密码**只属于这一个 Linux 发行版**，与 Windows 账户完全无关，两者互不影响。
- 用户名建议使用**纯英文小写**，只能包含小写字母、数字和短横线 `-`，并以字母开头。
- **输入密码时，屏幕上不会显示任何内容。** 这称为盲人键入。 你不会看到你正在键入的内容，这是完全正常的。
- 密码不需要和 Windows 密码相同，也不会影响 Windows 登录。它主要用于执行 `sudo` 时验证身份，设置一个简单好记的密码即可。
- 此帐户将被视为 Linux 管理员，能够运行 `sudo` (Super User Do) 管理命令。
- 每安装一个 Linux 发行版，都需要为它单独配置一套用户账户；重新安装或重置发行版后也要重新设置。

::: tip 修改或找回密码
随时可以在 Ubuntu 终端中输入 `passwd` 修改密码：先输入当前密码，再设置并确认新密码。
如果忘记了密码，可以在 PowerShell 中执行 `wsl -u root` 以根用户身份进入发行版，然后执行 `passwd <username>`（`<username>` 替换为你的用户名）重置密码，完成后输入 `exit` 退出。若要操作非默认的发行版，使用 `wsl -d <DistroName> -u root`。
:::

## 验证安装

在 PowerShell 中运行：

```powershell
wsl --list --verbose
```

如果看到类似以下输出，说明安装成功：

```text
  NAME      STATE           VERSION
* Ubuntu    Running         2
```

看到 `Running` 和 `VERSION 2` 即表示 WSL 2 正在正常运行。

## 安装后的推荐配置

### 更新和升级软件包

Windows 不会自动更新 Linux 发行版，需要自行定期在 Ubuntu 终端中执行：

```bash
sudo apt update && sudo apt upgrade
```

前者刷新可用软件包的列表，后者将已安装的软件包升级到最新版本。执行时会要求输入你的 Linux 密码。

### 安装 Windows Terminal

[Windows Terminal](https://learn.microsoft.com/zh-cn/windows/terminal/get-started) 是微软官方的多标签页终端，支持 UTF-8 字符、GPU 加速渲染、自定义主题与快捷键，可在 Microsoft Store 免费安装。每安装一个 WSL 发行版，它都会自动生成对应的标签页配置，管理多个命令行环境时非常方便。

### 配置代码编辑器

推荐使用 [Visual Studio Code](https://code.visualstudio.com/) 配合官方 [WSL 扩展](https://marketplace.visualstudio.com/items?itemName=ms-vscode-remote.remote-wsl)：在 WSL 终端中进入项目目录后输入 `code .`（注意末尾的句点表示当前目录），即可用 VS Code 打开并直接编辑、调试 Linux 侧的代码，体验与本地开发几乎一致。

## 文件存储

- 在 Ubuntu 终端中输入 `explorer.exe .`（末尾的句点同样表示当前目录），可以直接用 Windows 文件资源管理器打开当前的 WSL 目录。
- 可以跨操作系统访问文件，但这可能会显著降低性能。若想获得最快的性能速度，文件应**存放在与所用工具相同的文件系统上**，否则跨系统访问会显著降低性能：
  - 使用 Linux 工具（在 Ubuntu 终端中写代码、编译、运行）时，把项目放在 Linux 文件系统里，例如 `\\wsl$\Ubuntu\home\<用户名>\Project`；
  - 使用 Windows 工具（PowerShell、Windows 侧编辑器）时，把项目放在 Windows 文件系统里，例如 `C:\Users\<用户名>\Project`。
