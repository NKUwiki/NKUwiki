Markdown 是一种轻量级标记语言。它使用纯文本格式编写文档，可与 HTML 混编，可导出多种格式的文件。简洁、高效、易读、易写。

> 在线体验一下 [Markdown 在线编辑器](https://www.markdownassistant.com/zh/)。

千万不要被「标记」「语言」吓到，Markdown 的语法十分简单，常用的标记符号不超过十个，用于日常写作记录绰绰有余，不到半小时就能完全掌握。

写 Markdown 时有两点值得先记住：

- **中文行文用全角标点**（`，。？！：；` 等），排版约定详见[网页写作排版规范](/pages/writing-guidelines/)；
- **语法符号必须用半角**（`#`、`*`、`-`、`|`、`>` 等），全角符号不会被识别，只会原样显示出来。

## 标题

`#` 的数量代表标题级别，`#` 与标题文字之间留一个空格。部分编辑器允许 `#标题` 这种不加空格的写法，但并非标准，建议统一加上空格，便于笔记的传播和学习。

```md
# 一级标题
## 二级标题
### 三级标题
#### 四级标题
```

本站的约定：一级标题由页面标题自动生成，正文从 `##` 开始写；`##` 与 `###` 会进入右侧目录，可以跳转。

## 段落与换行

段落之间用**空行**分隔；同一行写多久都不会自动换行。需要强制换行时，在行尾敲两个空格再回车，或者直接写 `<br>`。

```md
这是第一段。

这是第二段，这一行结尾有两个空格 →  
所以这里换到了下一行。
```

## 强调

| 写法 | 效果 | 用途 |
| ---- | ---- | ---- |
| `**粗体**` 或 `__粗体__` | **粗体** | 强调重点 |
| `*斜体*` 或 `_斜体_` | *斜体* | 书名、术语、外语词 |
| `***粗斜体***` | ***粗斜体*** | 极少数场合，慎用 |

本站的加粗会额外附带一条底部色带（与马克笔同色），这是站点样式而非 Markdown 标准行为，详见[本站特有的 Markdown 语法](/pages/MarkdownGuide/#文字强调)。

## 删除线

```md
~~这段文字已被划掉~~
```

~~这段文字已被划掉~~

适合标注过时的信息。

## 高亮

```md
==重点内容==
```

==重点内容==

高亮属于扩展语法，本站与 Typora 等编辑器均支持。本站的高亮（马克笔）还支持配色后缀，详见[本站特有的 Markdown 语法](/pages/MarkdownGuide/#文字强调)。

## 行内代码与代码块

行内代码用一对反引号包围，适合文件名、命令、按键：

```md
在终端输入 `pnpm dev` 启动本地预览。
```

代码块用三个反引号上下包围，标注语言名可获得语法高亮：

````md
```ts
export default defineConfig({})
```
````

```ts
export default defineConfig({})
```

本站还支持给代码块加标题栏（语言名后写 `title="文件名"`），属于站点扩展，见[本站特有的 Markdown 语法](/pages/MarkdownGuide/#代码块)。

## 引用

`>` 加空格前置，适合补充说明或原文摘录。引用可以嵌套，也可以包含其他 Markdown 元素：

```md
> 一层引用
>
> > 二层嵌套
>
> - 引用里还能放列表
```

## 列表

无序列表用 `-`、`*` 或 `+`，有序列表用 `数字.`，缩进两个空格即为子项：

```md
- 无序列表项
- 另一项
  - 缩进两格是子项

1. 有序列表项
2. 数字不必连续，渲染时自动编号
```

任务列表用 `- [ ]`（未完成）与 `- [x]`（已完成）：

```md
- [x] 已完成
- [ ] 待完成
```

::: warning 注意
本站的任务列表勾选框**仅作展示，不可交互**——文章是静态内容，读者的勾选不会保存。
:::

## 链接与图片

```md
[南开大学](https://www.nankai.edu.cn/)
[站内链接](/pages/Contributing/)
<https://www.nankai.edu.cn/>
![图片描述](/img/04/08/新开湖.png)
```

- 链接由方括号内的文字与圆括号内的地址组成，地址后可跟 `"标题"`，鼠标悬停时显示
- 文内跳转写 `#` 加章节名
- 尖括号可以直接把网址变成链接
- 图片的 `![方括号]` 里写**描述文字**，它会作为点击放大后的题注，也会被读屏软件朗读，请认真填写
- 本站正文图片点击可全屏预览、缩放、左右切换，构建期会自动注入宽高防止页面跳动

## 转义字符

在符号前加反斜杠，可以显示原本用于格式化的字符：

```md
\* 这里不会变成无序列表
```

## 内嵌 HTML

Markdown 涵盖范围之外的标签可以直接写 HTML。行内标签范围内 Markdown 语法照常解析，但 HTML 区块标签内部不会被处理：

```md
<center>简单的文字居中也可以这样</center>
```

只要会写，完全可以把 Markdown 当作 HTML 来写；`.md` 文件也可以直接导出成一个网页。

## 分割线

单独一行写三个以上的 `*`、`-` 或 `_`，前后留空行：

```md
---
```

## 表格

用 `|` 画出列，第二行是分隔线，其中的冒号决定对齐方式：

```md
| 功能   | 支持度 |
| ------ | :----: |
| 语法一 |   ✅   |
```

| 功能   | 支持度 |
| ------ | :----: |
| 语法一 |   ✅   |

- `:---` 左对齐、`:---:` 居中、`---:` 右对齐
- 单元格内可以加粗、写行内代码、放链接，但不能放标题、列表、图片
- 单元格里要显示竖线本身，用 `&#124;` 转义

## 脚注

```md
南开大学创建于 1919 年[^1]。

[^1]: 张伯苓创办，初名南开学校。
```

脚注内容会自动排到文章末尾，适合放参考文献和补充说明，不打断正文阅读。

## Emoji 表情

直接粘贴 emoji（😅），或者输入冒号加名称的短码：

```md
去露营了！:tent: 很快回来。
```

表情很全的中文站点推荐 [emojiall](https://www.emojiall.com/zh-hans)。

## 数学公式

本站已启用 KaTeX。行内公式用一对 `$` 包围，独立公式段用两对：

```md
当 $a \ne 0$ 时，方程 $ax^2 + bx + c = 0$ 有两个实数解。

$$ x = {-b \pm \sqrt{b^2-4ac} \over 2a} $$
```

要显示美元符号本身而不触发公式渲染，用反斜杠转义（`\$`）或放进行内代码。

## 自定义容器

VitePress 内置的提示容器，适合写注意事项。容器标记与内容之间**要空一行**：

```md
::: tip 小技巧
这里是提示内容。
:::
```

::: tip 小技巧
这里是提示内容。
:::

可用的类型：`tip`（绿）/ `info`（灰）/ `note`（灰）/ `warning`（橙）/ `danger`（红）/ `caution` / `important`。本站还扩展了步骤条与时间线两种容器，见[本站特有的 Markdown 语法](/pages/MarkdownGuide/#步骤条与时间线)。

## 自动目录

`[TOC]` 是编辑器插件的功能（如 VS Code 的 Markdown All in One），写在哪就生成哪份目录。本站会**自动生成右侧大纲**，无需手写，正文里也不要再放一份目录。
