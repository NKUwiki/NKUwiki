Markdown 是一种轻量级标记语言。它使用纯文本格式编写文档，可与 HTML 混编，可导出多种格式的文件。简洁、高效、易读、易写。

> 在线体验一下 [Markdown 在线编辑器](https://www.markdownassistant.com/zh/)。

千万不要被「标记」「语言」吓到，Markdown 的语法十分简单，常用的标记符号不超过十个，用于日常写作记录绰绰有余，不到半小时就能完全掌握。

本篇按 [Markdown Guide 的基础语法](https://www.markdownguide.org/basic-syntax/)与[扩展语法](https://www.markdownguide.org/extended-syntax/)两份清单逐条覆盖：**基础语法**是原始设计文档里的元素，几乎所有应用都支持；**扩展语法**由各处理器自行扩充，用前先看本文标注的本站支持情况。本站专属的扩展（马克笔配色、行内注释等）不在这里，见[本站特有的 Markdown 语法](/pages/MarkdownGuide/)。

写 Markdown 时有两点值得先记住：

- **中文行文用全角标点**（`，。？！：；` 等），排版约定详见[网页写作排版规范](/pages/writing-guidelines/)；
- **语法符号必须用半角**（`#`、`*`、`-`、`|`、`>` 等），全角符号不会被识别，只会原样显示出来。

## 基础语法

### 标题

`#` 的数量代表标题级别，最多六级。`#` 与标题文字之间**必须留一个空格**——部分编辑器允许 `#标题` 这种写法，但并非标准，各家处理不一致，建议统一加上空格。标题前后也各留一个空行，兼容性最好。

```md
# 一级标题
## 二级标题
### 三级标题
#### 四级标题
```

还有一种「备用写法」：在文字下一行写一串 `=`（一级）或 `-`（二级）。它能用，但可读性差、且容易和分割线混淆，本文不推荐，统一用 `#` 写法。

本站的约定：**一级标题由页面标题自动生成，正文从 `##` 开始写**；`##` 与 `###` 会进入右侧目录，可以点击跳转。

### 段落

段落之间用**空行**分隔。同一段写多久都不会自动换行，不要用空格或制表符缩进段落——那样可能被误判成代码块。

```md
这是第一段。

这是第二段。
```

### 换行

在一行末尾敲两个以上空格再回车，可以强制换行；也可以直接写 `<br>` 标签。行尾空格在编辑器里看不出来，也容易误触，**更推荐用 `<br>`**。

```md
这是第一行。<br>
这是第二行。
```

### 强调

加粗用两个星号或两个下划线，斜体用一个，粗斜体用三个：

```md
**粗体** 与 __粗体__
*斜体* 与 _斜体_
***粗斜体***
```

- **粗体**
- *斜体*
- ***粗斜体***

只强调一个词的中间部分时，把符号紧贴字母写（`Love**is**bold`）。注意：**词中间用星号，不要用下划线**——各应用对词中下划线的处理不一致（`Love__is__bold` 在很多应用里不生效）。

::: tip 本站的加粗会长一条色带
本站给 `**粗体**` 额外附加了一条底部色带（与马克笔同色），这是站点样式而非 Markdown 标准行为。它随全站样式生效，没有单独开关——这是刻意的设计，详见[本站特有的 Markdown 语法](/pages/MarkdownGuide/#文字强调)。
:::

### 引用

`>` 加空格前置，适合补充说明或原文摘录。引用可以包含多个段落、可以嵌套、也可以放标题列表等其他元素：

```md
> 一层引用，第一段。
>
> 一层引用，第二段。
>
> > 这是嵌套的二层引用。
>
> - 引用里还能放列表
```

引用前后各留一个空行，兼容性最好。

### 列表

无序列表用 `-`、`*` 或 `+`，有序列表用 `数字.`，缩进两个空格即为子项：

```md
- 无序列表项
- 另一项
  - 缩进两格是子项

1. 有序列表项
2. 数字不必连续，渲染时自动编号
```

- 无序列表项
- 另一项
  - 缩进两格是子项

1. 有序列表项
2. 数字不必连续，渲染时自动编号

几个容易踩的点：

- 有序列表**从 1 开始**即可，后面的数字乱序也能正确编号，但不要用 `1)` 代替 `1.`——不是所有应用都支持
- 同一个列表里**不要混用** `-`、`*`、`+`，挑一种用到底
- 列表项要以「数字 + 句点」开头时，用反斜杠转义句点：`- 1968\. A great year!`

任务列表用 `- [ ]`（未完成）与 `- [x]`（已完成）：

```md
- [x] 已完成
- [ ] 待完成
```

::: warning 注意
本站的任务列表勾选框**仅作展示，不可交互**——文章是静态内容，读者的勾选不会保存。
:::

### 代码

行内代码用一对反引号包围，适合文件名、命令、按键：

```md
在终端输入 `pnpm dev` 启动本地预览。
```

要显示的反引号本身超过一个时，用两个反引号作定界符：

```md
用 `` `代码` `` 包住要显示的内容。
```

代码块也可以不用围栏，改用**四个空格或一个制表符缩进**——这是最原始的写法，围栏写法普及后已很少用。

### 转义

在符号前加反斜杠，可以显示原本用于格式化字符的符号：

```md
\* 这里不会变成无序列表

- 1968\. 也不会被当成有序列表
```

表格单元格里的竖线不适用反斜杠，要用 HTML 字符代码 `&#124;`，见[表格](#表格)。

### 分割线

单独一行写三个以上的 `*`、`-` 或 `_`，前后留空行：

```md
---
```

### 链接

链接由方括号内的文字与圆括号内的地址组成，地址后可以跟一个可选的 `"标题"`，鼠标悬停时显示：

```md
[南开大学](https://www.nankai.edu.cn/ "南开大学官网")
```

- 链接文字放方括号，地址放圆括号，可选的标题跟在地址后用引号包起来
- 站内链接用文章的 `permalink`
- 文内跳转写 `#` 加章节名，如 `[回到标题](#标题)`
- 地址里有空格时用 `%20` 代替，如 `[链接](https://example.com/my%20page)`
- 用尖括号可以直接把网址变成链接：`<https://www.nankai.edu.cn/>`

### 图片

图片语法比链接多一个感叹号，方括号里写**替代文字**，圆括号里写图片地址，同样可以跟 `"标题"`：

```md
![新开湖](/img/04/08/新开湖.png "八里台校区新开湖")
```

给图片包一层链接，就得到一张可以点击跳转的图片：

```md
[![新开湖](/img/04/08/新开湖.png)](https://www.nankai.edu.cn/)
```

本站的两个细节：图片的**描述文字会作为点击放大后的题注**，也会被读屏软件朗读，请认真填写；本地图片构建期会自动注入宽高，防止页面加载时跳动。

## 扩展语法

扩展语法不是原始设计文档的内容，各应用支持情况不一。下面每一条都标注了**本站是否支持**——标注不支持的，投稿时请不要使用。

### 表格

用 `|` 画出列，第二行是分隔线，其中的冒号决定对齐方式：

```md
| 功能   | 支持度 |
| ------ | :----: |
| 语法一 |   ✅   |
```

| 功能   | 支持度 |
| ------ | :----: |
| 语法一 |   ✅   |

- `:---` 左对齐、`:---:` 居中、`---:` 右对齐，不写冒号默认左对齐
- 单元格里可以加粗、写行内代码、放链接，但不能放标题、引用、列表、图片
- 单元格里要显示竖线本身，用 `&#124;` 转义
- 列的宽窄不影响渲染，源码里对齐只是为了好看

### 围栏代码块

代码块用三个反引号或三个波浪号上下包围，标注语言名可获得语法高亮：

````md
```json
{
  "name": "NKUwiki"
}
```
````

```json
{
  "name": "NKUwiki"
}
```

本站还支持给代码块加标题栏（语言名后写 `title="文件名"`），见[本站特有的 Markdown 语法](/pages/MarkdownGuide/#代码块)。

### 脚注

✅ 本站支持。脚注可以给文章加注释和参考文献，而不打断正文阅读：

```md
南开大学创建于 1919 年[^1]。

[^1]: 张伯苓创办，初名南开学校。
```

脚注内容会自动排到文章末尾，按出现顺序编号，不必写在文档最后。

### 标题编号

✅ 本站支持。给标题加大括号包起来的自定义 ID，可以精确控制锚点：

```md
### 马克思主义学院 {#marxism}
```

本站所有标题都会**自动生成 ID**（取标题文字本身），所以日常写作用不到这个语法；只有标题文字过于简单、容易和别的标题撞车时才需要手写指定。

### 定义列表

⚠️ **本站不支持**。定义列表用于「术语 — 定义」的对照：

```md
允公允能
: 南开校训，意指既有公德又有能力。

日新月异
: 南开校训，意指不断更新、不断发展。
```

本站渲染时上面这段会变成普通段落。请改用普通列表或表格；会 HTML 的话也可以直接写 `<dl><dt>…</dt><dd>…</dd></dl>`。

### 删除线

✅ 本站支持。用两个波浪号包围，适合标注过时信息：

```md
~~这段文字已被划掉~~
```

~~这段文字已被划掉~~

### 任务列表

✅ 本站支持。写法见[列表](#列表)一节。本站仅作展示，不可交互。

### Emoji

✅ 本站支持。直接粘贴 emoji，或者输入冒号加名称的短码：

```md
去露营了！:tent: 很快回来。
```

表情很全的中文站点推荐 [emojiall](https://www.emojiall.com/zh-hans)。注意短码因应用而异，不是所有编辑器都认。

### 高亮

✅ 本站支持。用两个等号包围：

```md
==重点内容==
```

==重点内容==

高亮语法并不普及，本站与 Typora 等编辑器支持。本站的高亮（称「马克笔」）还支持配色后缀 `{.tip}` / `{.caution}` / `{.warning}`，并与加粗共用同一条色带，详见[本站特有的 Markdown 语法](/pages/MarkdownGuide/#文字强调)。

### 下标

⚠️ **本站不支持**。下标用一个波浪号包围（`H~2~O`），本站渲染时波浪号会原样显示。需要时请用行内代码（`H~2~O`）或直接写 HTML `<sub>2</sub>`。

### 上标

⚠️ **本站不支持**。上标用一个插入符包围（`X^2^`）。需要时请用行内代码（`X^2^`）或直接写 HTML `<sup>2</sup>`；写数学幂运算更推荐用[公式](#数学公式)（$X^2$）。

### 自动链接

✅ 本站支持。很多处理器会把裸网址自动变成链接，本站也会：

```md
https://www.nankai.edu.cn/
```

https://www.nankai.edu.cn/

不想让网址变成链接，用反引号把它包起来即可：`` `https://www.nankai.edu.cn/` ``。

## 本站补充的两节

以下两节不属于上面两份清单，但本站常用，写在这里备查。

### 数学公式

本站已启用 KaTeX。行内公式用一对 `$` 包围，独立公式段用两对：

```md
当 $a \ne 0$ 时，方程 $ax^2 + bx + c = 0$ 有两个实数解。

$$ x = {-b \pm \sqrt{b^2-4ac} \over 2a} $$
```

要显示美元符号本身而不触发公式渲染，用反斜杠转义（`\$`）或放进行内代码。

### 提示容器

VitePress 内置的提示容器，适合写注意事项。容器标记与内容之间**要空一行**：

```md
::: tip 小技巧
这里是提示内容。
:::
```

::: tip 小技巧
这里是提示内容。
:::

可用的类型：`tip`（绿）/ `info`（灰）/ `note`（灰）/ `warning`（橙）/ `danger`（红）/ `caution` / `important`。本站还扩展了步骤条与时间线两种容器，见[本站特有的 Markdown 语法](/pages/MarkdownGuide/#步骤条与时间线)。
