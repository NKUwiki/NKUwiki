Markdown 是一种轻量级标记语言。它使用纯文本格式编写文档，可与 HTML 混编，可导出多种格式的文件。简洁、高效、易读、易写。

> 在线体验一下 [Markdown 在线编辑器](https://www.markdownassistant.com/zh/)。

千万不要被「标记」「语言」吓到，Markdown 的语法十分简单，常用的标记符号不超过十个，用于日常写作记录绰绰有余，不到半小时就能完全掌握。

需要注意的是，我们在写文本的时候大多写的是中文，然而中文下的标点是全角标点，如 `，。？！（）【】：；""` 等，这些标点不被 Markdown 语法所认可。但正文行文里的中文标点仍按全角书写（排版约定见[网页写作排版规范](/pages/writing-guidelines/)）——不被识别的是**把全角符号当语法用**，如全角的 `＃`、`＊`、`－`，它们只会原样显示出来。

本篇条目按 [Markdown Guide 的基础语法](https://www.markdownguide.org/basic-syntax/)与[扩展语法](https://www.markdownguide.org/extended-syntax/)两份清单选取，其中基础语法按 [CommonMark 帮助页](https://commonmark.org/help/) 的顺序编排；只收本站支持的条目（定义列表、上标、下标本站不渲染，未列入）。本站专属的扩展（马克笔配色、行内注释等）见[本站特有的 Markdown 语法](/pages/MarkdownGuide/)，想一页查完所有写法看[语法速查表](/pages/MarkdownCheatsheet/)。

## 基本语法

### 斜体

用一个星号或一个下划线包围：

| Markdown 语法 | HTML | 预览效果 |
| --- | --- | --- |
| `*斜体*` | `<em>斜体</em>` | *斜体* |
| `_斜体_` | `<em>斜体</em>` | _斜体_ |
| `A*cat*meow` | `A<em>cat</em>meow` | A*cat*meow |

适合书名、术语、外语词。只强调一个词的中间部分时，把符号紧贴字母写。注意**词中间用星号，不要用下划线**——各应用对词中下划线的处理不一致（`A_cat_meow` 在很多应用里不生效）。

### 粗体

用两个星号或两个下划线包围：

| Markdown 语法 | HTML | 预览效果 |
| --- | --- | --- |
| `**粗体**` | `<strong>粗体</strong>` | **粗体** |
| `__粗体__` | `<strong>粗体</strong>` | __粗体__ |
| `Love**is**bold` | `Love<strong>is</strong>bold` | Love**is**bold |

::: tip 本站的加粗会长一条色带
本站给 `**粗体**` 额外附加了一条底部色带（与马克笔同色），这是站点样式而非 Markdown 标准行为，详见[本站特有的 Markdown 语法](/pages/MarkdownGuide/#文字强调)。
:::

### 粗斜体

三个星号或三个下划线，粗体与斜体同时生效：

| Markdown 语法 | HTML | 预览效果 |
| --- | --- | --- |
| `***粗斜体***` | `<strong><em>粗斜体</em></strong>` | ***粗斜体*** |
| `___粗斜体___` | `<strong><em>粗斜体</em></strong>` | ___粗斜体___ |

部分处理器输出 `<em><strong>`，标签顺序相反、效果相同。三种强调叠在一起辨识度低，日常写作慎用。

### 标题

`#` 的数量代表标题级别，最多六级。`#` 与标题文字之间**必须留一个空格**，标题前后也各留一个空行，兼容性最好。

| Markdown 语法 | HTML | 预览效果 |
| --- | --- | --- |
| `# 一级标题` | `<h1>` | <h1>Heading level 1</h1> |
| `## 二级标题` | `<h2>` | <h2>Heading level 2</h2> |
| `### 三级标题` | `<h3>` | <h3>Heading level 3</h3> |

一级和二级还有一种「底线写法」：在文字下一行写一串 `=` 或 `-`。它是 CommonMark 认可的标准写法，本站也支持，但和分割线容易混淆，日常仍推荐 `#` 写法：

```md
一级标题
=========

二级标题
---------
```

| ✅ 这样做 | ❌ 不要这样做 |
| --- | --- |
| `# 标题`（井号后留空格） | `#标题`（并非标准，各家处理不一致） |

本站的约定：**一级标题由页面标题自动生成，正文从 `##` 开始写**；`##` 与 `###` 会进入右侧目录，可以点击跳转。

### 段落

| Markdown 语法 | HTML | 预览效果 |
| --- | --- | --- |
| 两行文字之间空一行 | 两个 `<p>` | 分成两段 |

```md
这是第一段。

这是第二段。
```

同一段写多久都不会自动换行。不要用空格或制表符缩进段落——那样可能被误判成代码块。

### 换行

在一行末尾敲两个以上空格再回车，可以强制换行；也可以直接写 `<br>` 标签。

| Markdown 语法 | HTML | 预览效果 |
| --- | --- | --- |
| 行尾两个以上空格 | `<br>` | 强制换行 |
| 行尾写 `<br>` | `<br>` | 强制换行 |

行尾空格在编辑器里看不出来，也容易误触，**更推荐用 `<br>`**。

### 链接

| Markdown 语法 | HTML | 预览效果 |
| --- | --- | --- |
| `[南开大学](https://www.nankai.edu.cn/)` | `<a href="…">南开大学</a>` | [南开大学](https://www.nankai.edu.cn/) |
| `[南开大学](https://www.nankai.edu.cn/ "官网")` | 加 `title="官网"` | 悬停显示标题 |
| `<https://www.nankai.edu.cn/>` | 同上 | 尖括号直接变链接 |
| `[回到标题](#标题)` | `<a href="#标题">` | 文内跳转 |

- 链接文字放方括号，地址放圆括号，可选的标题跟在地址后用引号包起来
- 站内链接用文章的 `permalink`
- 地址里有空格时用 `%20` 代替，如 `[链接](https://example.com/my%20page)`

同一个地址在文中反复出现时，可以用**引用式链接**：正文里写两组方括号，地址统一放在别处的「定义」里。标签与地址的对应关系写在文档任意位置（列表、引用、表格内除外）：

```md
[南开大学][nk] 创建于 1919 年，[南开大学教务处][jwc] 负责本科教学。

[nk]: https://www.nankai.edu.cn/ "南开大学官网"
[jwc]: https://jwc.nankai.edu.cn/
```

还有两种更短的写法：第二组方括号留空（`[南开大学][]`），或整组省略（`[南开大学]`，此时定义标签必须和链接文字相同）。三种写法本站都支持，标签大小写不敏感。投稿时统一用行内式（`[文字](地址)`）就好——引用式的价值在「一处改地址、全文生效」，日常短链接体现不出来。

### 图片

图片语法比链接多一个感叹号，方括号里写**替代文字**，圆括号里写图片地址，同样可以跟 `"标题"`：

| Markdown 语法 | HTML | 预览效果 |
| --- | --- | --- |
| `![替代文字](/img/xx.png)` | `<img src="…" alt="替代文字">` | 显示图片 |
| `![替代文字](/img/xx.png "标题")` | 加 `title="标题"` | 悬停显示标题 |
| `[![替代文字](/img/xx.png)](https://…)` | 图片外包 `<a>` | 图片可点击跳转 |

```md
![Apex 英语辩论社](/img/03/03/Apex英语辩论社.png)
```

![Apex 英语辩论社](/img/03/03/Apex英语辩论社.png)

图片的**替代文字**会被读屏软件朗读，也会作为点击放大后的题注，请认真填写。本站本地图片构建期会自动注入宽高，防止页面加载时跳动。图片地址一般不重复，引用式图片（`![文字][标签]`）很少用到。

### 引用

`>` 加空格前置，适合补充说明或原文摘录：

| Markdown 语法 | HTML | 预览效果 |
| --- | --- | --- |
| `> 引用文字` | `<blockquote>` | > 引用文字 |

引用可以包含多个段落、可以嵌套、也可以放标题列表等其他元素：

```md
> 一层引用，第一段。
>
> 一层引用，第二段。
>
> > 这是嵌套的二层引用。
>
> - 引用里还能放列表
```

引用前后各留一个空行，兼容性最好。

### 无序列表

列表项前加 `-`、`*` 或 `+`：

| Markdown 语法 | HTML | 预览效果 |
| --- | --- | --- |
| `- 列表项` | `<ul><li>` | - 列表项 |
| `* 列表项` | `<ul><li>` | - 列表项 |
| `+ 列表项` | `<ul><li>` | - 列表项 |

缩进两个空格即为子项：

```md
- 无序列表项
- 另一项
  - 缩进两格是子项
```

- 无序列表项
- 另一项
  - 缩进两格是子项

同一个列表里**不要混用** `-`、`*`、`+`，挑一种用到底。列表项要以「数字 + 句点」开头时，用反斜杠转义句点：`- 1968\. A great year!`。带勾选框的任务列表属扩展语法，见[任务列表](#任务列表)。

### 有序列表

列表项前加数字和句点：

| Markdown 语法 | HTML | 预览效果 |
| --- | --- | --- |
| `1. 列表项` | `<ol><li>` | 1. 列表项 |
| `1) 列表项` | `<ol><li>` | 1. 列表项 |

**从 1 开始**即可，后面的数字乱序也能正确编号：

```md
1. 有序列表项
2. 数字不必连续，渲染时自动编号
```

1. 有序列表项
2. 数字不必连续，渲染时自动编号

分隔符用句点（`1.`）。CommonMark 也认可右括号（`1)`），本站同样支持，但为兼容其他工具，建议统一用句点。

### 分割线

单独一行写三个以上的 `*`、`-` 或 `_`，前后留空行：

| Markdown 语法 | HTML | 预览效果 |
| --- | --- | --- |
| `---` | `<hr>` | 一条横线 |
| `***` | `<hr>` | 一条横线 |
| `___` | `<hr>` | 一条横线 |

### 行内代码

行内代码用一对反引号包围，适合文件名、命令、按键：

| Markdown 语法 | HTML | 预览效果 |
| --- | --- | --- |
| `` `代码` `` | `<code>代码</code>` | `代码` |
| 两个反引号作定界符 | `<code>`代码`</code>` | 显示反引号本身 |

要显示的反引号超过一个时，用两个反引号作定界符：

```md
用 `` `代码` `` 包住要显示的内容。
```

### 代码块

代码块用三个反引号或三个波浪号上下包围，标注语言名可获得语法高亮：

````md
```json
{
  "name": "NKUwiki"
}
```
````

```json
{
  "name": "NKUwiki"
}
```

| Markdown 语法 | HTML |
| --- | --- |
| 三个反引号，上下各一行 | `<pre><code>` |
| 三个波浪号，上下各一行 | `<pre><code>` |
| 四个空格或一个制表符缩进 | `<pre><code>`（最初的标准写法，现已很少用） |

围栏写法是后来加入的（Markdown Guide 把它归在扩展语法里），CommonMark 已将其纳入规范。本站还支持给代码块加标题栏（语言名后写 `title="文件名"`），见[本站特有的 Markdown 语法](/pages/MarkdownGuide/#代码块)。

### 转义

在符号前加反斜杠，可以显示原本用于格式化字符的符号：

| Markdown 语法 | HTML | 预览效果 |
| --- | --- | --- |
| `\*` | `*` | \* |
| `- 1968\.` | `1968.` | 1968\. |

表格单元格里的竖线不适用反斜杠，要用 HTML 字符代码 `&#124;`，见[表格](#表格)。

## 扩展语法

以下条目本站均支持（参考清单里的定义列表、上标、下标本站不渲染，未列入）。

### 表格

用三个或多个连字符创建每列的标题，使用管道符分隔每一列。为兼容考虑，行的两端也各加一个管道符：

```md
| 功能   | 支持度 |
| ------ | :----: |
| 语法一 |   ✅   |
```

呈现的输出如下所示：

| 功能   | 支持度 |
| ------ | :----: |
| 语法一 |   ✅   |

- `:---` 左对齐、`:---:` 居中、`---:` 右对齐，不写冒号默认左对齐
- 单元格里可以加粗、写行内代码、放链接，但不能放标题、引用、列表、图片
- 单元格里要显示竖线本身，用 `&#124;` 转义
- 列的宽窄不影响渲染，源码里对齐只是为了好看

### 脚注

脚注可以给文章加注释和参考文献，而不打断正文阅读。在方括号内添加插入符号和标识符创建脚注引用，再用「插入符号 + 标识符 + 冒号 + 内容」写脚注本身：

```md
南开大学创建于 1919 年[^1]。

[^1]: 张伯苓创办，初名南开学校。
```

脚注内容会自动排到文章末尾，按出现顺序编号，不必写在文档最后。标识符可以是数字或单词，但不能包含空格或制表符。

### 标题编号

给标题加大括号包起来的自定义 ID，可以精确控制锚点：

```md
### 马克思主义学院 {#marxism}
```

HTML 看起来像这样：

```html
<h3 id="marxism">马克思主义学院</h3>
```

本站所有标题都会**自动生成 ID**（取标题文字本身），所以日常写作用不到这个语法；只有标题文字过于简单、容易和别的标题撞车时才需要手写指定。链接到自定义 ID 用 `#` 加 ID，如 ``[马克思主义学院](#marxism)``。

### 删除线

用两个波浪号包围，适合标注过时的信息：

| Markdown 语法 | HTML | 预览效果 |
| --- | --- | --- |
| `~~文字~~` | `<s>文字</s>` | ~~文字~~ |

### 任务列表

任务列表让列表项带上勾选框，适合清单、进度类内容：

```md
- [x] 已完成
- [ ] 待完成
```

- [x] 已完成
- [ ] 待完成

::: warning 注意
本站的任务列表勾选框**仅作展示，不可交互**——文章是静态内容，读者的勾选不会保存。
:::

### Emoji

直接粘贴 emoji，或者输入冒号加名称的短码：

```md
去露营了！:tent: 很快回来。
```

去露营了！⛺很快回来。

表情很全的中文站点推荐 [emojiall](https://www.emojiall.com/zh-hans)。注意短码因应用而异，不是所有编辑器都认。

### 高亮

用两个等号包围：

| Markdown 语法 | HTML | 预览效果 |
| --- | --- | --- |
| `==文字==` | `<mark>文字</mark>` | ==文字== |

高亮语法并不普及，本站与 Typora 等编辑器支持。本站的高亮（称「马克笔」）还支持配色后缀 `{.tip}` / `{.caution}` / `{.warning}`，并与加粗共用同一条色带，详见[本站特有的 Markdown 语法](/pages/MarkdownGuide/#文字强调)。

### 自动链接

很多处理器会把裸网址自动变成链接，本站也会：

```md
https://www.nankai.edu.cn/
```

https://www.nankai.edu.cn/

不想让网址变成链接，用反引号把它包起来即可：`` `https://www.nankai.edu.cn/` ``。

## 本站补充的两节

以下两节不属于上面两份清单，但本站常用，写在这里备查。

### 数学公式

本站已启用 KaTeX。行内公式用一对 `$` 包围，独立公式段用两对：

```md
当 $a \ne 0$ 时，方程 $ax^2 + bx + c = 0$ 有两个实数解。

$$ x = {-b \pm \sqrt{b^2-4ac} \over 2a} $$
```

要显示美元符号本身而不触发公式渲染，用反斜杠转义（`\$`）或放进行内代码。需要上标、下标效果的场合（幂运算、化学式等）也用公式表达：$X^2$、$H_2O$——Markdown 自带的上下标写法本站不渲染，不要使用。

### 提示容器

VitePress 内置的提示容器，适合写注意事项。容器标记与内容之间**要空一行**：

```md
::: tip 小技巧
这里是提示内容。
:::
```

::: tip 小技巧
这里是提示内容。
:::

可用的类型：`tip`（绿）/ `info`（灰）/ `note`（灰）/ `warning`（橙）/ `danger`（红）/ `caution` / `important`。本站还扩展了步骤条与时间线两种容器，见[本站特有的 Markdown 语法](/pages/MarkdownGuide/#步骤条与时间线)。
