写作时放在手边的一页速查：**表格里的元素名都可以点**，直达对应文章的详细说明。想系统学习看[常见语法](/pages/markdown-syntax/)（基础语法按 [CommonMark 帮助页](https://commonmark.org/help/) 的顺序编排），投稿写法看[本站特有的 Markdown 语法](/pages/MarkdownGuide/)，编辑器与快捷键看[编辑软件对比](/pages/MarkdownEditors/)。

## 基础语法

| 元素 | 写法 | 效果 |
| --- | --- | --- |
| [斜体](/pages/markdown-syntax/#斜体) | `*文字*` | *文字* |
| [粗体](/pages/markdown-syntax/#粗体) | `**文字**` | **文字**（本站附带底部色带） |
| [粗斜体](/pages/markdown-syntax/#粗斜体) | `***文字***` | ***文字*** |
| [标题](/pages/markdown-syntax/#标题) | `## 二级标题` | 进右侧目录，可跳转 |
| [段落](/pages/markdown-syntax/#段落) | 空行分隔 | 自动成段 |
| [换行](/pages/markdown-syntax/#换行) | 行尾两空格或 `<br>` | 强制换行 |
| [链接](/pages/markdown-syntax/#链接) | `[文字](地址 "标题")` | [南开大学](https://www.nankai.edu.cn/) |
| [图片](/pages/markdown-syntax/#图片) | `![描述](/img/xx.png)` | 点击可全屏预览 |
| [引用](/pages/markdown-syntax/#引用) | `> 文字` | 引用块，可嵌套 |
| [无序列表](/pages/markdown-syntax/#无序列表) | `- 项` | 列表项 |
| [有序列表](/pages/markdown-syntax/#有序列表) | `1. 项` | 自动连续编号 |
| [分割线](/pages/markdown-syntax/#分割线) | `---` | 单独一行，前后留空行 |
| [行内代码](/pages/markdown-syntax/#行内代码) | `` `代码` `` | `代码` |
| [代码块](/pages/markdown-syntax/#代码块) | 三个反引号上下包围 | 按语言高亮 |
| [转义](/pages/markdown-syntax/#转义) | `\*` | 显示符号本身 |

## 扩展语法

⚠️ 一栏是本站支持情况：标 ⚠️ 的投稿时不要用。

| 元素 | 写法 | 效果 | 本站 |
| --- | --- | --- | --- |
| [表格](/pages/markdown-syntax/#表格) | `\| 列 \| 列 \|` | 第二行 `:---:` 控制对齐 | ✅ |
| [脚注](/pages/markdown-syntax/#脚注) | `文字[^1]` + `[^1]: 说明` | 脚注自动排到文末 | ✅ |
| [标题编号](/pages/markdown-syntax/#标题编号) | `### 标题 {#id}` | 自定义锚点 | ✅ |
| [删除线](/pages/markdown-syntax/#删除线) | `~~文字~~` | ~~文字~~ | ✅ |
| [任务列表](/pages/markdown-syntax/#任务列表) | `- [x]` / `- [ ]` | 仅展示，不可交互 | ✅ |
| [Emoji](/pages/markdown-syntax/#emoji) | `:tent:` 或直接粘贴 | ⛺ / 😅 | ✅ |
| [高亮](/pages/markdown-syntax/#高亮) | `==文字==` | ==文字==（本站称「马克笔」） | ✅ |
| [自动链接](/pages/markdown-syntax/#自动链接) | 裸网址 | 自动变成链接 | ✅ |
| [定义列表](/pages/markdown-syntax/#定义列表) | `术语` + `: 定义` | 本站按普通段落渲染 | ⚠️ |
| [下标](/pages/markdown-syntax/#下标) | `H~2~O` | 本站按原文渲染 | ⚠️ |
| [上标](/pages/markdown-syntax/#上标) | `X^2^` | 本站按原文渲染 | ⚠️ |

## 本站专属扩展

| 元素 | 写法 | 效果 |
| --- | --- | --- |
| [马克笔配色](/pages/MarkdownGuide/#文字强调) | `==文字=={.tip}` | 提示·绿 / 注意·黄 / 警告·红 |
| [行内注释](/pages/MarkdownGuide/#行内注释与隐秘文本) | `文字{^注释}` | ※ 气泡，悬停显示 |
| [隐秘文本](/pages/MarkdownGuide/#行内注释与隐秘文本) | `!!文字!!{.click}` | 黑幕遮住，悬停或点击显示 |
| [代码块标题](/pages/MarkdownGuide/#代码块) | 语言名后写 `title="文件名"` | 代码块带标题栏 |
| [步骤条](/pages/MarkdownGuide/#步骤条与时间线) | `::: steps` + 有序列表 | 分步流程 |
| [时间线](/pages/MarkdownGuide/#步骤条与时间线) | `::: timeline` + `time=""` | 带节点的竖向时间线 |
| [思维导图](/pages/MarkdownGuide/#思维导图) | 代码块语言写 `markmap` | 可缩放导图 |
| [仓库卡片](/pages/MarkdownGuide/#组件) | `<RepoCard repo="owner/name" />` | 星标 / License / 可见性 |
| [图片画廊](/pages/MarkdownGuide/#组件) | `<Gallery>…图片…</Gallery>` | 等高铺满排版 |
| [横滑轮播](/pages/MarkdownGuide/#组件) | `<WikiSwiper>…图片…</WikiSwiper>` | 可左右滑动 |
| [应用卡片](/pages/MarkdownGuide/#组件) | `<AppCards :links="[…]">` | 应用网格 |
| [分享长图](/pages/MarkdownGuide/#组件) | `<DownloadPageImage />` | 导出当前页长图 |

::: warning 两条最容易踩的坑
- 组合写法必须**马克笔在外**：`==**文字**==` 可以，`**==文字**==` 会让 `**` 原样显示出来；
- 包裹型组件（`<Gallery>` 等）的标签与内容之间**必须留空行**，内容才会按 Markdown 解析。
:::

## 编辑器快捷键（VS Code）

完整对比与插件推荐见[编辑软件对比](/pages/MarkdownEditors/)，快捷键全表在[常用快捷键](/pages/MarkdownEditors/#常用快捷键)。

| 按键 | 效果 |
| --- | --- |
| `Ctrl` + `B` / `Ctrl` + `I` | 加粗 / 倾斜 |
| `Alt` + `S` | 删除线 |
| `Ctrl` + `D` / `Ctrl` + `L` | 选中当前词 / 行 |
| `Ctrl` + `P` | 搜索文件并打开 |
| `Ctrl` + `.` | 切换全角 / 半角标点 |
