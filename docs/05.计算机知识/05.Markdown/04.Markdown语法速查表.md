写作时放在手边的一页速查：左看写法，右看效果。每类的详细说明见[常见语法](/pages/markdown-syntax/)，本站专属扩展见[本站特有的 Markdown 语法](/pages/MarkdownGuide/)。

## 基础语法

| 元素 | 写法 | 效果 |
| --- | --- | --- |
| 标题 | `## 二级标题`<br>`### 三级标题` | 进右侧目录，可跳转 |
| 粗体 | `**文字**` | **文字**（本站附带底部色带） |
| 斜体 | `*文字*` | *文字* |
| 粗斜体 | `***文字***` | ***文字*** |
| 删除线 | `~~文字~~` | ~~文字~~ |
| 行内代码 | `` `代码` `` | `代码` |
| 代码块 | 三个反引号上下包围，首行标注语言 | 按语言高亮 |
| 引用 | `> 文字` | > 引用块，可嵌套 |
| 无序列表 | `- 项` | - 列表项 |
| 有序列表 | `1. 项` | 1. 自动连续编号 |
| 任务列表 | `- [x]` / `- [ ]` | 勾选框仅展示，不可交互 |
| 链接 | `[文字](地址 "标题")` | [南开大学](https://www.nankai.edu.cn/) |
| 自动链接 | `<https://example.com>` | <https://example.com> |
| 图片 | `![描述](/img/xx.png)` | 点击可全屏预览 |
| 分割线 | `---` | 单独一行，前后留空行 |
| 转义 | `\*` | 显示符号本身 |

## 扩展语法

| 元素 | 写法 | 效果 |
| --- | --- | --- |
| 高亮 | `==文字==` | ==文字==（本站称「马克笔」） |
| 表格 | `\| 列 \| 列 \|` | 第二行 `:---:` 控制对齐 |
| 脚注 | `文字[^1]` + `[^1]: 说明` | 脚注自动排到文末 |
| 标题编号 | `### 标题 {#id}` | 自定义锚点（部分编辑器支持） |
| Emoji | `:tent:` 或直接粘贴 | ⛺ / 😅 |
| 行内公式 | `$E=mc^2$` | $E=mc^2$ |
| 公式块 | `$$ … $$` | 独立成段居中 |
| 自定义容器 | `::: tip 标题` … `:::` | tip / info / warning / danger 等 |
| 内嵌 HTML | `<center>文字</center>` | 区块标签内不解析 Markdown |

## 本站专属扩展

| 元素 | 写法 | 效果 |
| --- | --- | --- |
| 马克笔配色 | `==文字=={.tip}` | 提示·绿 / 注意·黄 / 警告·红 |
| 行内注释 | `文字{^注释}` | ※ 气泡，悬停显示 |
| 隐秘文本 | `!!文字!!{.click}` | 黑幕遮住，悬停或点击显示 |
| 代码块标题 | 首行语言名后写 `title="文件名"` | 代码块带标题栏 |
| 步骤条 | `::: steps` + 有序列表 | 分步流程 |
| 时间线 | `::: timeline` + `time=""` | 带节点的竖向时间线 |
| 思维导图 | 代码块语言名写 `markmap`，块内写列表 | 可缩放导图 |
| 仓库卡片 | `<RepoCard repo="owner/name" />` | 星标 / License / 可见性 |
| 图片画廊 | `<Gallery>…图片…</Gallery>` | 等高铺满排版 |
| 横滑轮播 | `<WikiSwiper>…图片…</WikiSwiper>` | 可左右滑动 |
| 应用卡片 | `<AppCards :links="[…]">` | 应用网格 |
| 分享长图 | `<DownloadPageImage />` | 导出当前页长图 |

::: warning 两条最容易踩的坑
- 组合写法必须**马克笔在外**：`==**文字**==` 可以，`**==文字**==` 会让 `**` 原样显示出来；
- 包裹型组件（`<Gallery>` 等）的标签与内容之间**必须留空行**，内容才会按 Markdown 解析。
:::

## 编辑器快捷键（VS Code）

| 按键 | 效果 |
| --- | --- |
| `Ctrl` + `B` / `Ctrl` + `I` | 加粗 / 倾斜 |
| `Alt` + `S` | 删除线 |
| `Ctrl` + `D` / `Ctrl` + `L` | 选中当前词 / 行 |
| `Ctrl` + `P` | 搜索文件并打开 |
| `Ctrl` + `.` | 切换全角 / 半角标点 |

更多编辑器对比与插件推荐见[Markdown 编辑软件对比](/pages/MarkdownEditors/)。
