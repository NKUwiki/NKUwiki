Markdown 只是一种语法，`.md` 文件用记事本都能打开，但要「写得舒服、看得即时」，还需要一个称手的编辑器。这一篇先横向对比常见选择，再给出本站投稿的推荐方案。

## 对比总览

| 编辑器 | 类型 | 预览方式 | 价格 | 导出格式 | 适合谁 |
| --- | --- | --- | --- | --- | --- |
| VS Code | 代码编辑器 + 插件 | 分屏实时预览 | 免费 | 借助插件 | 同时写代码与文档、愿意自己搭配环境 |
| Typora | 专用 Markdown 编辑器 | 所见即所得 | 付费（买断） | PDF / HTML / Word 等 | 只想专注写作、不想分屏 |
| Obsidian | 本地笔记软件 | 所见即所得 | 个人免费 | PDF 等 | 知识管理、双向链接笔记 |
| WPS | 办公套件 | 阅读视图 | 免费 / 会员 | Word / PDF | 偶尔查看、办公场景流转 |
| StackEdit 等在线编辑器 | 网页应用 | 所见即所得 | 免费 | HTML / PDF | 不想装软件、临时改稿 |

## 逐个简评

**VS Code**——免费开源、插件生态最丰富，缺点是开箱只支持基础语法，装插件、调配置要花一点时间。对要长期写技术文档、顺便改代码的人，这份投入很值。

**Typora**——写作体验最顺的专用编辑器，打完字即时渲染，没有源码与预览的割裂感；对高亮等扩展语法支持也全。1.0 之后转为收费（一次买断），只写文章的话是省心之选。

**Obsidian**——以本地 `.md` 文件为核心的笔记软件，强项是双向链接与知识图谱，适合把零散笔记织成网络的人；个人使用免费。

**WPS**——国内办公场景最常见，能直接打开 `.md` 文件，方便把文档转给只用 Office 的同事，但 Markdown 写作体验不是它的重点。

**在线编辑器（StackEdit 等）**——打开网页就能写，存档在云端，适合在机房或别人电脑上临时改稿；依赖网络，也不适合长篇。

## 本站投稿推荐：VS Code 上手

投稿给本站，推荐用 **VS Code**：免费、跨平台，且下文[常见语法](/pages/markdown-syntax/)与[本站特有语法](/pages/MarkdownGuide/)里的写法都能在它的预览里直接验证。

### 安装

从 [VS Code 官网](https://code.visualstudio.com/) 下载安装包，安装时除可手动指定路径外，一路下一步即可；也可以通过 Microsoft Store 静默安装。

### 推荐插件

VS Code 本身支持基础 Markdown 语法，但目录生成、PDF 导出、公式图表渲染等功能需要插件。在扩展面板搜索下列插件安装：

| 插件 | 功能 |
| :-: | :-: |
| Markdown All in One | 一键加粗、斜体、删除线，自动生成目录（TOC），列表与编号自动续写 |
| Markdown Preview Enhanced | 实时渲染文本、公式、图表，接近所见即所得 |
| Markdown PDF | 一键导出 PDF |
| Paste Image | 粘贴剪贴板图片时自动插入并保存到本地 |
| markdownlint | 自动检查并高亮不规范的写法 |

大部分场景只装 **Markdown All in One** 和 **Markdown Preview Enhanced** 就够了，其余按需再装。

### 常用快捷键

| 按键 | 效果 |
| --- | --- |
| `Ctrl` + `B` | 加粗当前选中 |
| `Ctrl` + `I` | 倾斜当前选中 |
| `Alt` + `S` | 删除线当前选中 |
| `Ctrl` + `D` | 选中当前词 |
| `Ctrl` + `L` | 选中当前行 |
| `Ctrl` + `P` | 搜索文件并打开 |
| `Ctrl` + `.` | 切换全角 / 半角标点 |
| `Ctrl` + `,` | 打开偏好设置 |

::: warning 全角与半角
写中文时行文内用全角标点，但 **Markdown 语法符号必须用半角**——`#`、`*`、`-`、`|` 等写成全角不会生效，只会原样显示。排版约定详见[网页写作排版规范](/pages/writing-guidelines/)。
:::

::: tip 编辑器扩展语法不一定通用
各家编辑器有自己的扩展语法（定义列表、上下标之类），**本站不一定支持**——本地预览正常，发到投稿可能不渲染。请以[常见语法](/pages/markdown-syntax/)与[本站特有语法](/pages/MarkdownGuide/)里列出的写法为准。
:::

## 怎么选

- **要给本站投稿、顺便写代码** → VS Code
- **只写文章、追求顺滑** → Typora
- **想经营长期知识库** → Obsidian
- **临时改一稿、不想装软件** → StackEdit 在线版
- **只用 WPS** → 也能打开 `.md`，但写作体验有限

语法本身不挑编辑器，选定一个后把[常见语法](/pages/markdown-syntax/)过一遍，半小时就能开始写了。
