**Markdown** 是一种轻量级标记语言。它使用纯文本格式编写文档，可与 HTML 混编，可导出多种格式的文件。简洁、高效、易读、易写。

> 在线体验一下 [Markdown 在线编辑器](https://www.markdownassistant.com/zh/)。

千万不要被「标记」「语言」吓到，Markdown 的语法十分简单，常用的标记符号不超过十个，用于日常写作记录绰绰有余，不到半小时就能完全掌握。

::: info 加粗色带
上表「粗体」那格的底色不是渲染出错：本站给所有 `**加粗**` 刷了一层底部色带，`==文字==` 用同一层色带但不加粗（本站管它叫「马克笔」）。这两处都是本站的视觉约定——同样的写法换到别的平台，就是普通的粗体与黄色高亮。
:::

::: tip 本站的链接与图片写法
语法与上表相同，区别只在路径怎么填：

- 站内链接写文章的 `permalink`（如 `/pages/Contributing/`），不要用文件相对路径
- 图片统一以 `/img/` 开头，配图优先传[图床上传器](https://upload.freshnkuer.wiki)、不必入库（详见[贡献指南](/pages/Contributing/)）

另外 `![描述]` 里的描述会作为点击放大后的题注显示，请认真填写；本地图片的宽高由构建期自动写入，不用手写尺寸（详见[站点功能说明](/pages/SiteFeatures/#图片预览-lightbox)）。
:::
