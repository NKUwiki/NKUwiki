## 标题

正文从 `##` 开始用（`#` 一级标题由系统按 `title` 自动生成，正文再写会出现两个 h1）；`##` 与 `###` 会进入右侧目录。

```md
## 二级标题（进目录）

### 三级标题（进目录）
```

## 马克笔配色

`==文字==` 本身是**通用高亮语法**（Obsidian、Typora、Logseq 都支持，GitHub 不认），完整写明在[常见扩展语法](/pages/markdown-extended/#高亮)。本站在此基础上加了两件事，因此称它为「马克笔」：

- **配色后缀**：`==必背=={.tip}`，带配色的是 `tip`（绿）/ `caution`（黄）/ `warning`（红）三种；写 `{.info}`、`{.note}` 这类与容器同名的类名会输出到 `class` 上但不着色、落回默认色带，其余自定义类名以 `wiki-marker-<类名>` 的形式输出，都可以在样式里自行配色
- **画色带而不是铺底色**：与加粗共用同一条底部色带，加粗＝粗体＋色带，马克笔＝色带＋自左向右的描线动画，所以它比普通高亮更醒目

```md
==必背=={.tip} 与 ==易错点=={.warning}
```

==必背=={.tip} 与 ==易错点=={.warning}

::: warning 马克笔与加粗的组合顺序
`==**文字**==` 正常渲染；反过来写 `**==文字**==` 时，`**` 会退化成字面文本显示出来（markdown-it 的定界符配对不跨越容器边界）。两种写法视觉相同，统一用前者。
:::

色带的颜色与厚度由主题包的 `--wiki-emphasis-band` 与 `--wiki-emphasis-band-height` 两个变量统一控制（深浅色各一档）：加粗、马克笔、以及两者叠加时共用这一条色带，改令牌即可三处同步，不需要逐篇设置。

## 行内注释与隐秘文本

- 行内注释 `{^内容}`：渲染成一个圆圈 i 小图标，悬停/点按弹出气泡，适合名词解释（^ 后不要紧跟数字，避免误伤数学上标）：

	示例：南开大学{^简称「南开」，位于天津市}创建于 1919 年。

- 隐秘文本 `!!内容!!`：黑幕遮住、悬停显示，适合防剧透卖关子；`{.click}` 改为点击开合，`{.blur}` 改为模糊：

	示例：你知道吗， !!鲁迅!! 曾说过：" !!我没说过这句话！!! "。

## 组件

正文中可直接使用的常用组件（参数详见[站点功能说明](/pages/SiteFeatures/)）：

| 组件 | 用途 |
| ---- | ---- |
| `<RepoCard repo="vuejs/vitepress" />` | GitHub 仓库卡片（星标、License、可见性） |
| `<Gallery>…图片…</Gallery>` | 图片画廊（等高铺满排版） |
| `<WikiSwiper>…图片…</WikiSwiper>` | 横滑轮播 |
| `<AppCards :links="[…]">` | 应用卡片网格 |
| `<DownloadPageImage />` | 页面分享长图下载按钮 |

::: warning 组件与 Markdown 混写的注意点
`<Gallery>`、`<WikiSwiper>` 等包裹型组件的标签与内部内容之间**必须留空行**，内容才会被当作 Markdown 解析；`links` 这类属性值里不会渲染 Markdown 语法。
:::
